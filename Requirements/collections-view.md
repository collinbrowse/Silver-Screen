# Epic: Collections View (Movie Collections)

The detail screen for a movie collection.

| # | Story | Done |
| --- | --- | --- |

| 2 | Underneath the above is a list of movies (or parts) in the collection. Each cell contains: movie title, poster image, genres, and release date. | [x] |
