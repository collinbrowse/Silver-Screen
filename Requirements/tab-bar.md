# Epic: Tab Bar

The tab bar is Browse, Search, and Library.

| # | Story | Done |
| --- | --- | --- |
| 1 | Browse, Search, and Library are the tabs. Browse shows media (All, Movies, TV Series) across the width. Window (All, Now Playing, Upcoming) and sort (Popular, Top Rated, Alphabetical, Newest, Oldest) are in a Filters menu at the top right. A new launch opens Movies, All, and Popular. Switching media keeps the current window and sort. Sort is disabled for Now Playing and Upcoming, which use TMDB's own lists. | [x] |
| 2 | Search is a tab. The system search field sits at the top of that screen. | [x] |
